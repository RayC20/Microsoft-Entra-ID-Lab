# Microsoft Entra ID Lab

## Overview
This project is a hands-on Microsoft Entra ID lab that I completed to practice cloud-based identity and access management. The goal was to learn how IT administrators manage users, groups, accounts, and sign-in activity in a cloud environment.

## Technologies Used
- Microsoft Entra ID
- Microsoft Azure Portal
- Microsoft 365 Cloud Environment

## What I Did
- Navigated and worked with the Microsoft Entra admin environment
- Created and managed user accounts
- Created and managed groups
- Added users to groups
- Practiced disabling and re-enabling user accounts
- Reviewed user and account information
- Explored sign-in activity and logs

## Skills Demonstrated
- Identity and Access Management (IAM)
- Microsoft Entra ID
- Cloud Administration
- User and Group Management
- Account Management
- Basic Sign-In Monitoring
- IT Support
